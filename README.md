# openfox-codebase-memory

OpenFox plugin for [codebase-memory-mcp](https://github.com/JamesDAdams/codebase-memory-mcp) integration, featuring interactive structural knowledge graph visualization, auto-synchronization, and project management.

## Features

- **Project Discovery & Sync**: Automatically discovers OpenFox projects and syncs them with codebase-memory-mcp.
- **Interactive Graph Explorer**: Built-in Sandboxed Graph visualization UI directly inside OpenFox modals.
- **Composer Status & Quick Actions**: Fast header button and composer-top status indicators.
- **Multi-language Support**: Full English & French translations.
